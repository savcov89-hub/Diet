# Рацион·НСК — генератор недельного рациона

Веб‑приложение, которое по опроснику (пол, возраст, рост, вес, активность, цель, бюджет, непереносимости,
беременность, лактация, диабет 1/2 типа, ХБП) собирает меню на 7 дней из продуктов, доступных в Новосибирске,
так, чтобы в среднем за неделю выполнялись нормы МР 2.3.1.0253‑21 и ВОЗ, а стоимость корзины была минимальной
для выбранного уровня: эконом / бизнес / премиум.

Все расчёты выполняются в браузере (решатель HiGHS на WebAssembly), сервер не нужен.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest: проверка норм на 7 профилях (похудение, беременность, ХБП, СД1, веган, лактация, аллергии)
npm run build      # статическая сборка в dist/
npm run data:build # пересобрать src/data/products.json из каталога и USDA (скачает 6 МБ при первом запуске)
```

Скриншоты интерфейса: `npx vite preview` и затем `node scripts/screenshot.mjs`.

## Как это работает

1. **Энергия.** Базовый обмен по Миффлину – Сан Жеору × коэффициент активности МР (1,4 / 1,6 / 1,9 / 2,2).
   Беременность +250/+350 ккал по триместрам, лактация +500/+450 (МР 2021). Цель «снизить вес»: дефицит 500–700 ккал
   (КР «Ожирение» 2024), не ниже 1200/1500 ккал (AHA/ACC/TOS 2013), при лактации дефицит ≤500 и не ниже 1800 ккал
   (Lovelady 2000), при беременности дефицита нет, при ХБП — не ниже 30 ккал/кг.
2. **Нормы на день** (`src/core/norms.ts`). Витамины и минералы по МР 2.3.1.0253‑21 с учётом пола, возраста, триместра и
   периода лактации; верхние пределы EFSA/IOM; жиры ≤30 %, НЖК ≤10 %, транс ≤1 %, соль <5 г, клетчатка ≥25 г,
   овощи и фрукты ≥400 г (ВОЗ); белок 1,2–1,6 г/кг при похудении (Leidy 2015, Wycherley 2012), 0,6–0,8 г/кг при
   ХБП С3б–С5 и 1,0–1,2 на диализе (КР ХБП 2024, KDIGO 2024, KDOQI 2020); калий и фосфор по стадии ХБП; при диабете
   клетчатка ≥14 г/1000 ккал, добавленные сахара ≤5 %, исключение сахара/мёда/варенья, ХЕ по приёмам (1 ХЕ = 10 г).
3. **Корзина на неделю** (`src/core/solver.ts`). Задача смешанно-целочисленного программирования (HiGHS): минимизировать стоимость
   (в бизнес/премиум — с поправкой на «качество» продукта) при выполнении норм за 7 дней, лимитах на продукт и группу,
   долях разнообразия (ни один овощ >35 % овощей и т.п.) и минимумах (рыба ≥300 г, бобовые ≥150 г). Продукт либо не
   покупается, либо берётся не меньше реалистичного объёма (`min_week_g`: рыба 350–500 г, мясо 400 г, крупа 150 г).
   В списке покупок граммы пересчитываются в упаковки и тушки (`pack_g`, `pack_label`) с подсказкой, как покупать. Минимумы по
   витаминам — мягкие со штрафом: задача всегда решается, а недобор честно показывается (например, витамин D).
4. **Меню** (`src/core/planner.ts`). Порции раскладываются по дням и приёмам, выравнивая калории (и углеводы при
   диабете), чтобы в обед и ужин были овощи и не было двух гарниров.
5. **Доказательная база** (`src/core/evidence.ts`). Каждое правило ссылается на документ; список со ссылками есть на
   странице «Источники» в приложении.

## Вкусняшки

По умолчанию в рационе заложен бюджет на десерт ≈120 ккал/сут (можно выключить или поднять до ≈220) в пределах нормы ВОЗ
по добавленным сахарам (10 %, при похудении и диабете 5 %). Можно отметить любимое: зефир, пастила, мармелад, халва, овсяное
печенье, пряники, пломбир, шоколад, глазированный сырок, мёд, варенье. При диабете остаётся только горький шоколад.
Обоснование: гибкий контроль питания без полных запретов лучше удерживает вес (Westenhoefer 1999, Teixeira 2010).

## Дизайн

Визуальная система общая с приложением Training Log (репозиторий `savcov89-hub/Claude-cod`): те же токены цвета
(`--bg`, `--surface`, `--accent` и т.д. в `src/index.css`), шрифт Golos Text, скругление 14/10 px, нижняя панель навигации
на телефоне и боковая на десктопе. Если в Training Log поменяются токены, достаточно скопировать блок `:root` в `src/index.css`.

## Данные

- `data/etl/catalog.py` — 150 продуктов: русские названия, категория, теги (lactose, gluten, egg, fish, nuts, soy, pork,
  red_meat, pregnancy_avoid, added_sugar, high_gi, siberia …), цены по трём уровням (руб/кг), сезонность, роли в приёмах
  пищи, недельные лимиты, идентификатор USDA. **Цены правятся здесь.**
- `data/etl/build_products.py` — собирает `src/data/products.json` из каталога и USDA FoodData Central SR Legacy
  (public domain, 35 нутриентов на 100 г). Йод и облепиха добавлены вручную по Скурихину (2002) и помечены.
- Цены: ориентир октябрь 2026 (Новосибирскстат, ценовой замер НГС по Центральному рынку и «Магниту», Росстат по НСО);
  позиции с экспертной оценкой помечены флагом `est` и знаком «≈» в списке покупок.

## Структура

```
data/etl/            каталог продуктов и ETL
src/core/            ядро без UI: energy, norms, rules, solver, planner, evaluate, evidence
src/ui/              опросник, результат (меню / покупки / нормы), источники
src/data/            products.json (генерируется)
tests/               vitest
public/highs.wasm    решатель
```

## Ограничения и что дальше

- Нормы для взрослых 18+. Дети, беременность с диабетом, диализ и тяжёлые состояния — только как ориентир для
  обсуждения с врачом; приложение показывает соответствующие предупреждения.
- В USDA SR Legacy мало данных по витамину D и йоду; недобор витамина D может быть завышен, йод заведён вручную.
- Цены — ручная таблица; следующий шаг — импорт средних цен Росстата (ЕМИСС) скриптом и админ‑страница.
- Фаза 2 по плану (`docs/PLAN.md`): рецептурник с названиями блюд, аккаунты и сохранение истории, Telegram‑бот,
  бренды и штрихкоды из Open Food Facts.
